Privacy Policy

Effective date: November 24, 2026

This policy covers the Creature Codex website and the Creature Codex application, a private tool that the channel owner uses to publish the channel's own videos. The application is not offered to the public and is used only with the channel owner's Google account.

This website

The website has no accounts, forms, cookies, analytics or ads. It is hosted on GitHub Pages, which may keep technical logs such as IP addresses for security, as described in the GitHub Privacy Statement.

What the application accesses

When the channel owner signs in with Google, the application asks for permission to use:

  • YouTube Data API: to upload the channel's videos, set their titles, descriptions, thumbnails, subtitles, playlists and release dates, and to read the status of the channel's own videos (for example, whether a video is scheduled or public).
  • Google Calendar API, limited to calendars the application creates: to keep a "Creature Codex" calendar with the channel's release schedule.

The application does not read, collect or store data about viewers, subscribers or any other person, and it does not access any other Google data.

How data is used and stored

  • The sign-in tokens and the publishing log are stored only on the channel owner's own computer.
  • Data obtained through Google APIs is used only to publish and manage the channel's own content as listed above.
  • It is never sold, shared with third parties, used for advertising, or used to train AI models.

The application's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

YouTube and Google

The application uses YouTube API Services. By using it you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy. Watching our videos on YouTube is governed by YouTube's own policies, not by this one.

Revoking access

Access can be revoked at any time from the Google Account permissions page. Locally stored tokens are deleted together with the application's files.

Changes and contact

If this policy changes, the new version will be posted on this page with a new effective date. Questions: creaturecodexofficial@gmail.com.
